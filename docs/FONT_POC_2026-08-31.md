# Wizardry VII PSX Korean font POC

Date: 2026-08-31
Branch: `tech/psx-font-poc`

## 목적

PS1판의 1바이트 ASCII 문자열이 `FUN_ASCIItoZENKAKU`를 거쳐 2바이트 문자 코드로 변환된 뒤 `FONT.MMT`에서 출력되는 경로를 확인하기 위한 최소 실험이다.

이번 POC는 ASCII `A` (`ZENKAKU.TBL` 결과 `0x80A5`)의 글리프만 임시로 한국어 `한`으로 교체한다.

## 확인된 FONT.MMT 구조

- 전체 크기: 50,724 bytes
- 헤더: 36 bytes
- 4bpp pixel payload: 50,688 bytes
- 논리 텍스처 크기: 1024 x 99 pixels
- y=0..2: CLUT/palette 영역
- glyph 영역은 y=3부터 시작
- glyph 높이: 12 pixels
- 한 16x12 물리 셀에 글리프 4개가 4개의 nibble bitplane으로 겹쳐 저장됨
- 렌더러가 문자 코드의 하위 2비트에 따라 CLUT를 골라 필요한 bitplane 한 개만 표시함

첫 글리프 행의 physical group 16에서는 다음이 확인됨.

- bit 0 = `9`
- bit 1 = `A`
- bit 2 = `B`
- bit 3 = `C`

따라서 POC는 physical group 16 / bit 1만 수정하며 `9`, `B`, `C` 데이터는 보존한다.

## 재생성

Git에 원본/수정 게임 데이터는 포함하지 않는다. 사용자가 보유한 원본 `FONT.MMT`에 다음 도구를 적용한다.

```bash
python tools/wiz7_psx_font_poc.py FONT.MMT FONT_A_to_HAN_POC.MMT
```

## 다음 테스트

생성된 `FONT_A_to_HAN_POC.MMT`를 게임 데이터의 `CDS/T/FONT.MMT` 대신 넣어 부팅한다.

게임 화면에서 원래 `A`가 표시되는 곳이 `한`으로 바뀐다면 다음 세 가지를 동시에 실증한다.

1. ASCII 1바이트 UI 문자열이 `FUN_ASCIItoZENKAKU` 경로를 사용한다.
2. `ZENKAKU.TBL`의 `A -> 0x80A5` 매핑 해석이 맞다.
3. `FONT.MMT`의 packed bitplane/CLUT 해석이 맞다.

이 테스트가 성공하면 같은 구조를 이용해 한국어 전용 코드표와 전체 한글 글리프 매핑으로 확장한다.
