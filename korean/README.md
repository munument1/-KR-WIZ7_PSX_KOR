# Wizardry VII PSX 한국어 번역 데이터

이 디렉터리는 PS1판 `Wizardry VII - Guardia no Houju` 한국어화용 UTF-8 번역 원고를 보관한다.

## 기준 원문

- PS1 영어패치의 `MSGHDR_indexText.txt`를 최종 기준 원문으로 사용한다.
- 기존 `Wizardry 7 Gold 한국어 번역 데이터`의 번역을 최대한 재사용한다.
- 단, PS1판과 DOS/Gold판이 같은 메시지 ID를 사용하더라도 영어 문장이 다르면 PS1 원문을 우선하여 다시 번역한다.
- 종족명, 직업명, 능력치, 지역명, NPC명 등은 기존 한국어판 용어를 우선 유지한다.
- 8000번대 이후에는 Gold와 PS1의 메시지 ID가 어긋나는 구간이 있으므로 ID 단순 복사가 아니라 PS1 영어 원문 문장 자체를 기준으로 대조한다.

## 파일 형식

기본 형식은 다음과 같다.

```text
메시지ID\한국어 텍스트
```

예:

```text
100\인간
120\전사
4003\화염구
```

현재 파일들은 **번역 원고**이며 아직 PS1 게임 데이터에 직접 삽입할 수 있는 빌드 결과물이 아니다.

## 제어코드

원본 문자열에는 일반 텍스트 외에 0x00~0x1F 등의 제어 바이트가 포함되어 있다.

번역 원고에서 확인이 필요한 제어 바이트는 다음처럼 표시한다.

```text
<0x01>
<0x16><0x01><0x02><0x01>
```

최종 삽입 도구는 번역 원고의 표시만 신뢰하여 원본 제어 시퀀스를 새로 구성하기보다, 가능한 경우 **PS1 영어 원문의 제어코드를 그대로 보존하고 텍스트 부분만 한국어로 교체**해야 한다.

`^`, `$`, `%`, `#`처럼 런타임 치환에 사용되는 기호와 `=951,` 같은 참조 토큰도 임의로 삭제하거나 변경하지 않는다.

## 번역 원칙

1. 게임 진행용 토큰과 제어코드는 번역하지 않는다.
2. NPC 및 고유명사는 기존 Wizardry VII 한국어 번역과 통일한다.
3. 같은 영어 원문은 가능하면 같은 한국어 용어를 사용한다.
4. 화면 폭 문제를 예상해 UI 문구는 의미를 해치지 않는 범위에서 짧게 번역한다.
5. PS1 전용 메모리 카드, 패드, 저장/불러오기 문구는 PS1판에 맞춰 별도로 번역한다.
6. 아직 용도가 불명확한 내부 토큰은 원문을 유지한다.
7. 7000번대처럼 NPC 입력 해석에 쓰이는 것으로 보이는 문법/동의어 사전은 일반 표시 문자열과 분리하여 다룬다. 실제 대화 판정에 영향을 줄 수 있으므로 구조 확인 전에는 빌드 대상 번역으로 취급하지 않는다.

## 보류 구간

- 7000번대 NPC 문장 해석용 키워드/동의어 사전
  - 번역 원문은 조사하되, 표시 텍스트와 달리 게임 로직에 관여할 가능성이 있으므로 삽입 방식 확정 전까지 별도 취급한다.

## 아직 하지 않은 것

- 전체 메시지 번역 완료
- PS1 전용 한글 문자 인코딩 확정
- Huffman 재압축 및 `MSGJ.DBS` 빌드
- 한글 폰트 삽입
- 실제 게임 화면에서 줄바꿈/폭 검수
- 캐릭터 이름 입력 화면의 한글 키보드화

실행 환경이 준비되기 전까지는 번역 원고를 먼저 최대한 완성하고, 이후 한글 렌더링과 데이터 삽입 단계로 넘어간다.
